Spring Security — CORS lab (API :8091)

CORS is enforced by the browser. Open the frontend from a different origin to see allow vs block.

End-to-end setup

  1. Keep this API running on http://localhost:8091
  2. Serve the frontend from http://localhost:5500:
cd spring-cors-demo/frontend
python3 -m http.server 5500

Then open http://localhost:5500

Allowlist

Only http://localhost:5500 is allowed (see cors.allowed-origins).

  • Allowed origin → browser exposes JSON to JS
  • Evil origin → browser blocks (no usable ACAO)
  • Preflight OPTIONS must succeed before credentialed POST

Quick curl checks

# Allowed origin — look for Access-Control-Allow-Origin
curl -i -H "Origin: http://localhost:5500" \
  http://localhost:8091/api/public/ping

# Blocked origin — no matching ACAO
curl -i -H "Origin: http://evil.example" \
  http://localhost:8091/api/public/ping

# Preflight for credentialed POST
curl -i -X OPTIONS http://localhost:8091/api/transfers \
  -H "Origin: http://localhost:5500" \
  -H "Access-Control-Request-Method: POST" \
  -H "Access-Control-Request-Headers: authorization,content-type"
