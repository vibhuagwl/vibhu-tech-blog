## Architecture

```text
Broker → Topic → Partition → Replica
Leader serves reads/writes · Followers replicate · ISR = caught-up set
```

## Producer

```text
BATCH → COMPRESS → SEND → RETRY
```

- `acks` · `batch.size` · `linger.ms` · compression · retries · idempotence

Detail: [batch.size](/kafka-interview/kafka-config-batch-size) · [Producer opt](/kafka-interview/kafka-optimization-producer)

## Consumer

```text
POLL → PROCESS → COMMIT
```

- group · offset · `max.poll.records` · `max.poll.interval.ms` · session timeout

Detail: [max.poll.records](/kafka-interview/kafka-config-max-poll-records) · [Consumer groups](/kafka-interview/kafka-knowledge-consumer-groups)

```text
Throughput ↔ Latency
Batching · Compression · Partitioning · Consumer count ≤ partitions
```
