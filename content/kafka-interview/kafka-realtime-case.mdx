## Run it

```bash
cd spring-kafka-payments-demo
docker compose up -d
mvn -q -DskipTests package

export SPRING_KAFKA_BOOTSTRAP_SERVERS=localhost:9092
mvn -q -pl payment-api spring-boot:run &
mvn -q -pl settlement-worker spring-boot:run &
```

```bash
# success
curl -X POST http://localhost:8091/api/payments \
  -H 'Content-Type: application/json' \
  -d '{"paymentId":"pay-1001","accountId":"acct-77","amount":"125.50","currency":"USD","merchantRef":"M-900","failMode":"NONE"}'

# poison → immediate DLQ
curl -X POST http://localhost:8091/api/payments \
  -H 'Content-Type: application/json' \
  -d '{"paymentId":"pay-1002","accountId":"acct-77","amount":"9.99","currency":"USD","merchantRef":"M-901","failMode":"POISON"}'

# transient → retry then maybe DLQ
curl -X POST http://localhost:8091/api/payments \
  -H 'Content-Type: application/json' \
  -d '{"paymentId":"pay-1003","accountId":"acct-77","amount":"18.50","currency":"USD","merchantRef":"M-902","failMode":"TRANSIENT_BANK_TIMEOUT"}'

curl http://localhost:8092/api/ops/processed
curl http://localhost:8092/api/ops/dlq
```

## Producer code — key + transaction

```java
String key = PaymentKeyStrategy.forPayment(request.accountId(), request.paymentId());
kafkaTemplate.executeInTransaction(ops -> {
    ops.send(PaymentTopics.PAYMENT_REQUESTS, key, event);
    return null;
});
```

```text
key = accountId + ":" + paymentId
→ same account stays ordered on one partition
```

---

## Consumer code — manual commit + DLQ

```java
factory.getContainerProperties().setAckMode(ContainerProperties.AckMode.MANUAL_IMMEDIATE);
factory.setCommonErrorHandler(errorHandler(kafkaTemplate));
```

```java
@KafkaListener(topics = PaymentTopics.PAYMENT_REQUESTS, groupId = "settlement-worker")
void onPayment(PaymentRequestedEvent event, Acknowledgment acknowledgment) {
    settlementService.process(event);
    acknowledgment.acknowledge();
}
```

```java
DeadLetterPublishingRecoverer recoverer = new DeadLetterPublishingRecoverer(
        kafkaTemplate,
        (record, ex) -> new TopicPartition(PaymentTopics.PAYMENT_REQUESTS_DLT, record.partition()));
DefaultErrorHandler handler = new DefaultErrorHandler(recoverer, new FixedBackOff(1000L, 2L));
handler.addRetryableExceptions(TransientSettlementException.class);
handler.addNotRetryableExceptions(PoisonPaymentException.class, IllegalArgumentException.class);
```

**Memory:** transient → retry · poison → DLQ now · ack only after success.

## Failure matrix

| Failure | What this code does |
|---|---|
| Broker slow | batch + retries |
| Duplicate send risk | producer idempotence |
| Poison payload | DLT immediately |
| Bank timeout | 2 retries then DLT |
| Crash before ack | redelivery + processed table dedupe |
| Hot account | ordered by key, watch hot partition |
