## Must-set before production (payment baseline)

### Producer

| Property | Prod target | Why |
|---|---|---|
| `acks` | `all` | Durability with ISR |
| `enable.idempotence` | `true` | Safe retries |
| `retries` / `delivery.timeout.ms` | high / sized | Transient blips |
| `linger.ms` / `batch.size` / `compression.type` | tuned / `zstd` or `lz4` | Throughput |
| `max.in.flight.requests.per.connection` | `≤5` with idempotence | Ordering + EOS |
| `transactional.id` (if EOS) | stable per instance | Fencing |

### Consumer

| Property | Prod target | Why |
|---|---|---|
| `enable.auto.commit` | `false` | Commit after business success |
| `auto.offset.reset` | explicit (`earliest`/`latest`/`none`) | Predictable start |
| `isolation.level` | `read_committed` if transactional upstream | LSO visibility |
| `max.poll.records` / `max.poll.interval.ms` | sized together | Avoid rebalance storms |
| `session.timeout.ms` / `heartbeat.interval.ms` | classic protocol | Liveness (N/A the same way if `group.protocol=consumer`) |
| `partition.assignment.strategy` | CooperativeSticky | Smoother rolls |
| `group.instance.id` | stable on k8s | Fewer restart rebalances |

### Broker / cluster / controller

| Property | Prod target | Why |
|---|---|---|
| `auto.create.topics.enable` | `false` | No typo topics |
| `default.replication.factor` / `min.insync.replicas` | `3` / `2` typical | Durability with `acks=all` |
| `unclean.leader.election.enable` | `false` | No silent loss |
| `advertised.listeners` | reachable DNS | Classic k8s foot-gun |
| `process.roles` / `controller.quorum.voters` / `node.id` | KRaft set | Metadata quorum |
| `log.retention.*` | business window | Replay horizon |
| `offsets.topic.replication.factor` / `transaction.state.log.replication.factor` | ≥3 | Internal topic HA |

### Security

| Layer | Properties |
|---|---|
| Clients | `security.protocol`, `sasl.mechanism`, `sasl.jaas.config`, SSL trust/keystore |
| Brokers | `listener.security.protocol.map`, inter-broker protocol, authorizer, ACLs |

---

## How properties interact

```text
Producer: acks=all + enable.idempotence=true + max.in.flight≤5 + retries>0
Consumer: max.poll.records × process_time < max.poll.interval.ms
Broker:   message.max.bytes ≥ client max.request.size
          replica.fetch.max.bytes ≥ message.max.bytes
KRaft:    odd controller.quorum.voters; majority must be alive for metadata commits
group.protocol=consumer → broker-side assignors; some classic timeout configs do not apply
```

## Topic-level configs (common)

Topic overrides live on the topic (via `kafka-configs` / Admin). Important ones:

| Property | Typical use |
|---|---|
| `retention.ms` / `retention.bytes` | Time/size retention |
| `cleanup.policy` | `delete`, `compact`, or both |
| `min.insync.replicas` | Topic durability override |
| `segment.bytes` / `segment.ms` | Segment roll |
| `max.message.bytes` | Per-topic size cap |
| `compression.type` | Topic default compression |
| `unclean.leader.election.enable` | Prefer leave false |
| `message.timestamp.type` | CreateTime vs LogAppendTime |

Full topic-level list: [Topic configs](https://kafka.apache.org/40/configuration/topic-level-configs/).

## GO / NO-GO

- Producer: idempotence + `acks=all` + batching/compression verified
- Consumer: manual commit + poll budget + retry/DLQ for poison
- Broker: auto-create off, RF/minISR, unclean=false, retention set
- Controller: odd quorum across AZs; monitor ActiveControllerCount / metadata health
- Security: SASL/SSL + ACLs from app pods
- Replay: earlier offset without double settlement (idempotent sink)
