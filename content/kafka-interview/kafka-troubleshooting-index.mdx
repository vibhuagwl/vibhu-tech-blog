## Playbook shape

```text
SYMPTOM → WHAT TO CHECK → METRICS → LOGS → ROOT CAUSES → FIX → PREVENTION
```

## Quick triage order

```text
1. Is the cluster healthy? (ISR, disk, broker down)
2. Is lag consumer-side? (processing, deps, poll config)
3. Are we thrashing on rebalances?
4. Is it data/poison/serialization?
5. Is it auth / network / timeouts?
```
