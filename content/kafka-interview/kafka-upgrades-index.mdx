## Mental model

Compatibility is a **chain**, not a single version number:

```text
Spring Boot
     ↓
Spring Kafka
     ↓
Kafka Client
     ↓
Kafka Broker
     ↓
Java runtime
```

Evaluate the whole chain. Do not hard-code uncertain matrices as facts — verify against your current BOMs and official compatibility notes for the versions you run.
