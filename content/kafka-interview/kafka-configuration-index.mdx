## Producer

| Property | What it controls | Default mindset | When to change | Risk | Learn more |
|---|---|---|---|---|---|
| `batch.size` | Max batch bytes before send | Throughput lever | Need higher throughput | Memory / latency | [→](/kafka-interview/kafka-config-batch-size) |
| `linger.ms` | Wait to fill batches | Pair with batch.size | Improve batching | Adds latency | [→](/kafka-interview/kafka-config-batch-size) |
| `compression.type` | Payload compression | Network vs CPU | Large messages / WAN | CPU | [Producer opt](/kafka-interview/kafka-optimization-producer) |
| `acks` | Durability acknowledgement | Durability vs latency | Stronger durability | Latency / availability | [Producer interview](/kafka-interview/kafka-producer-interview) |
| `enable.idempotence` | Safe retries | Prefer on for critical producers | Exactly-once-ish produce path | Config coupling | [Producer interview](/kafka-interview/kafka-producer-interview) |

## Consumer

| Property | What it controls | Default mindset | When to change | Risk | Learn more |
|---|---|---|---|---|---|
| `max.poll.records` | Records per poll | Processing budget | Lag or slow processing | Rebalances if too high | [→](/kafka-interview/kafka-config-max-poll-records) |
| `max.poll.interval.ms` | Time between polls | Must exceed processing | Long batch jobs | Masks stuck consumers if too high | [Consumer opt](/kafka-interview/kafka-optimization-consumer) |
| `session.timeout.ms` | Group membership | Pair with heartbeats | Unstable membership | False rebalances | [Consumer interview](/kafka-interview/kafka-consumer-interview) |
| `enable.auto.commit` | Auto offset commit | Prefer explicit for critical | Simpler non-critical apps | Lost / duplicate processing | [Offsets](/kafka-interview/kafka-offset-management-interview) |
| `auto.offset.reset` | Start position if no offset | Know your recovery story | New groups / reset | Replay or skip | [Offsets](/kafka-interview/kafka-offset-management-interview) |
