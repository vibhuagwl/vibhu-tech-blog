## Conflict pattern (reuse)

```text
Restate shared goal → criteria → options + data → decide → commit wholly
```

## Q74–Q88 — Technical & interpersonal conflict

| Prompt | Angle / story |
|---|---|
| Biggest disagreement / other architect | **D1** criteria + hybrid |
| Eng manager / PM conflict | Scope vs risk; phased options |
| Executive conflict | Business trade-off language |
| Two engineers fighting | Evidence rules; private coaching |
| Recommendation rejected | Document dissent; execute decision; revisit with metrics |
| Compromise / refuse compromise | Compromise on approach; refuse on money integrity / security |
| Changed opinion / changed theirs | Benchmarks; written RFCs |
| Opinionated / dominates room | Written proposals; rotate facilitation |
| Both sides valid | Hybrid or experiment with kill criteria |
| Politics | Make trade-offs public; avoid private deals that hide risk |

## Q89–Q100 — Executives & stakeholders

| Prompt | Answer skeleton |
|---|---|
| Disagree with executive | Options with customer/risk/cost; let them choose knowingly |
| Bad news / missed commitment | Early, with impact + recovery plan + ask |
| Reset expectations | New plan, cuts, dates, owners |
| Technical risk to execs | Likelihood × blast radius × $; mitigations |
| Non-technical architecture | “What it enables / what breaks / what it costs” |
| Fund initiative | ROI narrative (**C1**) |
| Unrealistic ask / deadline | Three options (**D1**) |
| Changing priorities | Priority stack visible; WIP limits |
| Ambiguous requirements | Create decision log + thin slice |
| Communicate uncertainty | Confidence ranges + validation gates |
