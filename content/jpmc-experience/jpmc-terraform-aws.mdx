## Story

```text
Terraform
  → modules / variables / locals / outputs
  → security groups
  → ALB + target groups
  → cluster / compute
  → certificates / TLS
  → app deploy hook
```

## Security group least privilege

```text
Internet → ALB :443 → app tier → internal services → DB
```

No wide-open 0.0.0.0/0 to app ports.

## terraform plan vs apply
Plan is preview; apply mutates. Halfway failure: state may be partial — inspect state, refresh, targeted recover, never “guess apply” blindly.

## Certificates
Create/store/attach · TLS termination on ALB · rotation · expiry monitoring

## Env separation
Workspaces or separate state + var files for DEV/UAT/STAGING/PROD. No prod secrets in code.
