## Example flow

```text
Request received
  → Validate
  → Create async request / tracker
  → Call external service
  → Wait (message/timer)
  → Receive callback/event
  → Validate response
  → Calculate (Drools)
  → Persist
  → Complete
```

## Why Camunda
Visible state, retries, timers, compensation hooks, human tasks for maker-checker — better than hidden thread sleeps.

## Interview Q
**How do you find a stuck workflow?**  
By business key / process instance id / tracker id; inspect current activity, incidents, and timers.
