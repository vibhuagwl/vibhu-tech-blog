## Cashlines / API

```text
Request → Security → Validation → Business → DB → Event → Response
```

## Kafka

```text
Producer → Topic → Partition → Consumer Group → Offset
  → Retry → DLQ → Replay → Idempotency → Monitoring
```

## CDC

```text
DB commit → Connector → Kafka → Consumer (idempotent) → Side effects
```

## Async tax

```text
Request → Correlation ID → Tracker → Workflow → External
  → Callback/Event → Update → Final status
```

## Replay safety

```text
Select → Validate → Dry-run → Rate-limit → Republish → Audit → Report
```

## Migration

```text
Java → Spring → Dependencies → Build → Test → Canary → Monitor → Rollback
```

## Incident

```text
Detect → Scope → Correlate → Mitigate → Recover → RCA → Fix → Prevent
```
