## Top 100

### 1. How did Cashlines work end to end?
**Model:** API→validate→DB→Kafka→consumer→status; dual-write aware.

### 2. DB committed, Kafka publish failed — then what?
**Model:** Outbox/CDC/retry publish; never ignore orphan states.

### 3. How do you make Kafka consumers idempotent?
**Model:** Business key / event id + unique constraints + state checks.

### 4. Retryable vs non-retryable?
**Model:** Timeouts/503 retry; invalid payload/schema to DLQ.

### 5. What does DefaultErrorHandler do?
**Model:** Retries with backoff then recoverer (often DLQ) then move on.

### 6. Explain your replay tool.
**Model:** Select DLQ msgs, validate, rate-limit republish, audit, report categories.

### 7. Replay causes duplicates — how safe?
**Model:** Idempotent consumers; duplicates become no-ops.

### 8. Ordering after replay?
**Model:** Replay in partition order; guard state transitions.

### 9. Why CDC?
**Model:** Committed DB as event source; reduce dual writes.

### 10. CDC duplicate events?
**Model:** At-least-once; idempotent apply by entity version/LSN.

### 11. Schema evolution strategy?
**Model:** Additive optional fields; registry compatibility.

### 12. Why Avro?
**Model:** Contract + evolution; confirm per-topic `{NEED}`.

### 13. Participant onboarding idempotency?
**Model:** Idempotency-Key or natural unique key.

### 14. Swagger value?
**Model:** Explicit contract; DTO boundary; fewer integration surprises.

### 15. Deloitte tax architecture?
**Model:** REST→Camunda→Drools→external→S3/SQS→tracker.

### 16. Why Camunda?
**Model:** Long-running visible state, timers, incidents, human tasks.

### 17. Why Drools vs if/else?
**Model:** Rule churn, testable decisions, business separation.

### 18. GraphQL vs REST here?
**Model:** Vendor API shape; still wrap with timeouts/retries.

### 19. S3 role?
**Model:** Store payloads/artifacts with IAM + encryption.

### 20. SQS crash before delete?
**Model:** Redelivery; idempotent processing required.

### 21. Async tracker fields?

### 22. Callback duplicate?

### 23. Spring Batch chunk tradeoff?

### 24. Large RSU file approach?
