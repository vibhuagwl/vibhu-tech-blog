## Methodology

1. Detect  
2. Scope  
3. Correlate (requestId, workflowId, offset, tracker)  
4. Investigate  
5. Mitigate  
6. Recover  
7. Validate  
8. RCA  
9. Permanent fix  
10. Prevent recurrence  

## Symptom → first checks
- API latency ↑ → deps, DB pool, GC, downstream  
- Kafka lag ↑ → processing vs cluster  
- Duplicates → idempotency gaps / double publish / redelivery  
- Wrong tax → rules version + input facts + external response  
- Stuck workflow → Camunda incidents/timers  
- Cert expiry → ALB/TLS errors spike  

## Spoken line
> I correlate one transaction across API logs, tracker row, workflow id, and Kafka partition/offset before changing anything in prod.
