## Flow

```text
Maker creates request
  → Validation
  → Pending approval
  → Checker reviews
  → Approve / Reject
  → Execute
  → Audit
```

## Why not only Java flags?
Need SoD, audit trail, timers/escalation, rework loops — workflow engines encode that state explicitly.
