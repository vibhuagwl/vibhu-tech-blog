## Trace fields

requestId · correlationId · transactionId · workflowId · topic/partition/offset · external request id · SQS message id · final status

## Per dependency

```text
Dependency → failure → detect → timeout → retry?
  → circuit/fallback → DLQ → manual recovery → alert
```

## When NOT to retry
Invalid payload, authZ deny, business rule reject, non-idempotent side effect without guard.

## Architecture question
Design distributed request tracking that lets support reconstruct one transaction in minutes.
