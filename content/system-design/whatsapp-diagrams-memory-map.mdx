## 20-second memory lines

```text
HTTPS = APIs
WebSocket = realtime
WebRTC = calls
Kafka = internal only
Redis = presence + registry + idempotency
S3+CDN = media
Shard key = conversationId
Order = partition + serverSeq
Duplicate = clientMsgId
Offline = DB + push + sync
```
