## Reminder

> Kafka is **not** the pipe between Alice’s phone and Bob’s phone. It is the **internal** async backbone after durable persist.

### Partition keys

| Topic | Key | Why |
|---|---|---|
| message.created | conversationId | Per-chat order |
| message.status | conversationId or messageId | Localize updates |
| group.events | groupId | Ordered membership |
| notification.requested | userId | Per-user notify order |

## Consumer settings (mental model)

```text
enable.auto.commit = false
ack after side effects + idempotent write
retries for transient
non-retryable → DLQ
```

### Java sketch

```java
@KafkaListener(topics = "message.created", groupId = "delivery")
public void onMessage(MessageCreated ev, Acknowledgment ack) {
    if (deliveryRepo.alreadyDelivered(ev.messageId(), ev.deviceId())) {
        ack.acknowledge();
        return;
    }
    delivery.push(ev);
    ack.acknowledge();
}
```

## Failure scenarios

<Mermaid chart={`sequenceDiagram
    participant K as Kafka
    participant C as Consumer
    participant DB as DB

    K->>C: event
    C->>DB: process OK
    Note over C: crash before commit
    K->>C: redelivery
    C->>DB: idempotent no-op
    C->>K: commit offset
`} />

| Scenario | Outcome |
|---|---|
| Crash before process | Redeliver → process |
| Crash after process before commit | Redeliver → idempotent |
| Broker fail | ISR elects leader; clients retry |
| Duplicate event | Idempotency key |
| Poison message | DLQ after N; unblock partition |
| Consumer lag | Scale consumers ≤ partitions; optimize handler |
| DLQ replay | Fix bug → replay with care |

## What NOT on Kafka

```text
Raw image/video bytes
WebRTC media
Client heartbeat floods
Typing fan-out at global scale without rate limits
```

---

## Interview explanation

> Persist then produce. Partition by conversationId. Consumers are idempotent with manual commits. Lag and poison messages are operational first-class citizens.
