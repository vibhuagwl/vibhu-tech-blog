## Goal

Compress confidence. Do not learn brand-new exotic architectures this week.

## Day 1 — Framework

Redraw from memory:

```text
Clarify → Estimate → API/Data → Naive → Bottlenecks
→ Evolve → Deep dive → Failures → Trade-offs
```

Rehearse *System Design Interview Preparation* out loud once.

## Day 2 — Data + cache + Kafka

Cheat sheets only + 10 flash prompts:

- SQL vs NoSQL choice
- Shard key mistakes
- Cache stampede
- Kafka ordering boundary
- Idempotent consumer

## Day 3 — Core designs A

45-min each (notes closed): URL Shortener, Rate Limiter, KV Store.

## Day 4 — Core designs B

News feed OR Instagram, Chat/WhatsApp, Notification.

## Day 5 — FinTech + reliability

Payment System + reliability patterns + anti-patterns list.

## Day 6 — Mocks

Two unknown prompts. Record yourself. Fix filler and missing failures.

## Day 7 — Light only

- Cheat sheets once
- Behavioral STAR outlines
- Sleep early

## Night-before card

```text
Ask clarifying questions
State assumptions
Estimate roughly
Draw simple first
Name bottlenecks
Pick DB from access patterns
Say trade-offs aloud
Cover timeout/retry/idempotency
End with 10× and monitoring
```
