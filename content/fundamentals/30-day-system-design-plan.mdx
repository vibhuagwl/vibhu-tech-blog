## Who this is for

Engineers with backend experience who need a sharp, interview-ready system-design loop in one month.

## Rules

- Speak answers out loud with a timer
- Every design must include failures and trade-offs
- Do not collect notes without redrawing architectures from memory

## Week 1 — Operating system

| Day | Focus |
|---|---|
| 1 | *System Design Interview Preparation* + Master Index |
| 2 | Requirements + NFRs drill (5 prompts) |
| 3 | *Capacity Estimation* — 10 calculation drills |
| 4 | *Trade-off Framework* + *Why Technology Choices* |
| 5 | CAP + consistency models |
| 6 | Load balancer + CDN mental models |
| 7 | Review + redraw 3 architectures blind |

## Week 2 — Data plane

| Day | Focus |
|---|---|
| 8 | *Database Decision Framework* |
| 9 | Indexing, replication, read replicas |
| 10 | Partitioning + *Consistent Hashing* |
| 11 | Redis article + cache invalidation drills |
| 12 | Kafka article + delivery semantics |
| 13 | CDC/Outbox + idempotency |
| 14 | Mini-mock: URL Shortener (45 min) |

## Week 3 — Full designs

| Day | Design |
|---|---|
| 15 | Rate Limiter |
| 16 | Distributed KV Store |
| 17 | Notification System |
| 18 | Instagram / news feed |
| 19 | WhatsApp / chat |
| 20 | Uber |
| 21 | Weakest design redo + cheat sheets |

## Week 4 — Reliability + defense

| Day | Focus |
|---|---|
| 22 | *Reliability Patterns* |
| 23 | *Architecture Anti-Patterns* |
| 24 | Payment System (FinTech correctness) |
| 25 | Multi-region + RPO/RTO drills |
| 26 | Behavioral: ownership + conflict stories |
| 27 | Full mock #1 (45 min unknown prompt) |
| 28 | Full mock #2 |
| 29 | Cheat sheet blitz |
| 30 | *7-Day Revision* preview + sleep |

## Daily 90-minute template

```text
20 min — concept article
40 min — timed design aloud
20 min — failure follow-ups
10 min — write 5 flashcards
```

## Success criteria

You can take an unfamiliar prompt and complete the framework without freezing, including capacity math and at least three failure modes.
