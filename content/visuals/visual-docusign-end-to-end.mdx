## 20-second interview version

- Envelope holds docs + recipients + status  
- Identity before sign (email / OTP / access code)  
- Hash document → sign with private key → attach cert + audit  
- Change bytes → signature invalid (tamper evident)  
- Connect webhook tells Spring Boot “completed”  

## Remember

E-sign trust = **identity + PKI + immutable audit**, not a PNG of a signature.
