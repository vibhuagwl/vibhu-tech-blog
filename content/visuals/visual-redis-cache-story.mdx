## 20-second interview version

- Cache-aside for hot reads  
- TTL + single-flight against stampede  
- Hot keys need extra tricks (local cache / split)  
- If Redis dies, protect the DB — don’t stampede  

## Remember

Redis is speed. Durability still needs a real source of truth.
