## What this is

A **runnable** Spring Security lab at `spring-authn-authz-demo/` that implements **authentication and authorization without OAuth**.

- **web-portal (:8080)** — form login, session (`JSESSIONID`), URL rules, `@PreAuthorize`
- **api-service (:8081)** — HTTP Basic, stateless, JSON APIs, same role model

There is **no** `/oauth2/authorize`, `/oauth2/token`, JWKS, or client registration.

## Authn vs Authz (in one app)

| Concern | Mechanism in this demo |
|---|---|
| Authentication | `UserDetailsService` + BCrypt + form login **or** HTTP Basic |
| Authorization | `authorizeHttpRequests` + role hierarchy + `@PreAuthorize` |

The OAuth Authorization Server is absent because each app **is** the security boundary.

## Interview punchline

> Without OAuth, Spring Security still does both authentication and authorization — locally. OAuth becomes necessary when you need delegated identity and tokens across apps you do not fully control.
