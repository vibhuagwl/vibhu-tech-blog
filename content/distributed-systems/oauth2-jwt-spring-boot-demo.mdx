## What this is

A **runnable** OAuth 2.0 + JWT lab lives in the repo at `oauth-jwt-demo/`.

Explain the full lifecycle in a Staff interview:

Who authenticates → who issues the code → who exchanges it → who signs the JWT → where keys live → who validates → scopes/roles → expiry/refresh → AS outage behavior.

## Stack

- Java 21, Spring Boot **3.4.5**, Spring Security 6.x
- Spring Authorization Server (Boot starter / BOM-managed)
- Resource Server + API Gateway + confidential client app
- Flyway user/OAuth JDBC schema; H2 locally, Postgres via Docker Compose

## Start here

## Mental model

```text
Login → Authorize → Code → Token (JWT RS256) → Gateway → Resource Server
  → JwtDecoder/JWKS → claims → SCOPE_/ROLE_ → @PreAuthorize → API
```

## Interview punchline

> The hard part is not wiring `oauth2ResourceServer`. It is key management, audience/scope design, refresh/rotation, and what still works when the Authorization Server is down.
