## Goal

After this track you should look at almost any coding problem and independently derive:

1. Time complexity  
2. Space complexity  
3. Auxiliary space  
4. Input space  
5. Best / average / worst case  

Core pattern for every guide:

```text
CODE
  ↓
NUMBER OF EXECUTIONS
  ↓
MATHEMATICAL FORMULA
  ↓
SIMPLIFICATION
  ↓
BIG-O
```

## Quick growth ladder

| Name | Growth | Intuition |
|---|---|---|
| O(1) | Constant | Array index, HashMap get (avg) |
| O(log N) | Logarithmic | Binary search, balanced BST |
| O(N) | Linear | Single scan |
| O(N log N) | Linearithmic | Merge / heap sort |
| O(N²) | Quadratic | Nested loops over N |
| O(2ᴺ) | Exponential | Subsets / naive recursion |
| O(N!) | Factorial | Full permutations |
