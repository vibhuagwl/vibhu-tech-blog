## How to use this curriculum

This Complexity track is designed for interview preparation.
Read it in order if you want the full derivation path, or jump to the quick tables when you need last-minute recall.

The rule across every guide:

```text
Do not memorize the answer first.
Derive the operation count, simplify the expression, then state the Big-O bound.
```

## Core derivation patterns

| Pattern | Exact count | Bound | Where it appears |
|---|---:|---:|---|
| Single scan | `N` | `O(N)` | linear search, array sum |
| Two scans | `N + N` | `O(N)` | min then max |
| Full nested loops | `N * N` | `O(N^2)` | all ordered pairs |
| Triangular loops | `N(N+1)/2` | `O(N^2)` | insertion sort shifts, unordered pairs |
| Doubling loop | `log2 N` | `O(log N)` | binary search, repeated doubling |
| Balanced divide | `N` per level times `log N` levels | `O(N log N)` | merge sort |
| Binary branching | `1+2+...+2^N` | `O(2^N)` | subsets, naive choices |

## Interview answer template

Use this when asked for time and space:

```text
Let N be ___.
The first part costs ___ because ___.
The second part costs ___ because ___.
Adding terms gives ___.
The dominant term is ___, so time is ___.
Extra space is ___ because ___.
Assumptions: ___.
```

Example:

```text
Let N be the number of elements.
Sorting costs O(N log N).
The two-pointer scan costs O(N) because each pointer moves monotonically.
Total time is O(N log N + N), which simplifies to O(N log N).
Extra space is O(1) excluding output, with sort implementation assumptions.
```
