## Problem

Derive sorting Big-O from loops, recursion trees, and input assumptions. Let `N` be item count, `K` key range, `D` digit passes, and `B` base or bucket count.

---

## Bubble sort

### Problem

Swap adjacent inverted elements until no swaps remain.

### Java Code

```java
static void bubbleSort(int[] a) {
    for (int pass = 0; pass < a.length - 1; pass++) {
        boolean swapped = false;
        for (int i = 0; i < a.length - 1 - pass; i++) {
            if (a[i] > a[i + 1]) {
                int t = a[i]; a[i] = a[i + 1]; a[i + 1] = t;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}
```

### Math

```text
worst comparisons = (N-1) + (N-2) + ... + 1
= N(N-1)/2
= O(N^2)
best with no swaps = O(N)
```

### Space

Only temporary variables: `O(1)`.

### Final

Bubble sort is best `O(N)`, average/worst `O(N^2)`, stable, and in-place.

### Interview Explanation

"The shrinking inner loop is an arithmetic series; early exit gives the linear best case."

## Selection sort

### Problem

Select the minimum remaining element and swap it into place.

### Java Code

```java
static void selectionSort(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        int min = i;
        for (int j = i + 1; j < a.length; j++) {
            if (a[j] < a[min]) min = j;
        }
        int t = a[i]; a[i] = a[min]; a[min] = t;
    }
}
```

### Math

```text
comparisons = (N-1) + (N-2) + ... + 1
= O(N^2)
swaps <= N-1 = O(N)
dominant cost = O(N^2)
```

### Space

Auxiliary space is `O(1)`.

### Final

Selection sort is `O(N^2)` best/average/worst, in-place, and usually unstable.

### Interview Explanation

"Even sorted input still scans every unsorted suffix."

## Insertion sort

### Problem

Insert each item into an already sorted prefix.

### Java Code

```java
static void insertionSort(int[] a) {
    for (int i = 1; i < a.length; i++) {
        int key = a[i], j = i - 1;
        while (j >= 0 && a[j] > key) a[j + 1] = a[j--];
        a[j + 1] = key;
    }
}
```

### Math

```text
worst shifts = 1 + 2 + ... + (N-1) = O(N^2)
best sorted input = one failed while check per i = O(N)
```

### Space

Auxiliary space is `O(1)`.

### Final

Insertion sort is best `O(N)`, average/worst `O(N^2)`, stable, and in-place.

### Interview Explanation

"It is adaptive because work tracks inversions."

## Merge sort

### Problem

Sort halves and merge the sorted halves.

### Java Code

```java
static void mergeSort(int[] a, int l, int r, int[] tmp) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    mergeSort(a, l, m, tmp);
    mergeSort(a, m + 1, r, tmp);
    merge(a, l, m, r, tmp);
}
```

### Math

```text
T(N) = 2T(N/2) + O(N)
work per level = N
levels = log2 N
T(N) = O(N log N)
```

### Space

Merge buffer `O(N)` plus stack `O(log N)`, so auxiliary space is `O(N)`.

### Final

Merge sort is `O(N log N)` best/average/worst, stable, and not in-place for arrays.

### Interview Explanation

"Linear merge work repeats for each halving level."

## Quick sort

### Problem

Partition around a pivot, then sort both sides.

### Java Code

```java
static void quickSort(int[] a, int lo, int hi) {
    if (lo >= hi) return;
    int p = partition(a, lo, hi);
    quickSort(a, lo, p - 1);
    quickSort(a, p + 1, hi);
}
```

### Math

```text
balanced: T(N) = 2T(N/2) + O(N) = O(N log N)
one-sided: T(N) = T(N-1) + O(N)
= N + (N-1) + ... + 1
= O(N^2)
```

### Space

Stack is `O(log N)` average and `O(N)` worst; partitioning is in-place.

### Final

Quick sort is average `O(N log N)`, worst `O(N^2)`, in-place, and usually unstable.

### Interview Explanation

"Pivot balance determines whether the recursion tree is logarithmic or linear depth."

## Heap sort

### Problem

Build a heap, then repeatedly extract the maximum.

### Java Code

```java
static void heapSort(int[] a) {
    buildMaxHeap(a);              // O(N)
    for (int end = a.length - 1; end > 0; end--) {
        swap(a, 0, end);
        heapifyDown(a, 0, end);   // O(log N)
    }
}
```

### Math

```text
build heap = O(N)
N extracts * O(log N) = O(N log N)
T(N) = O(N log N)
```

### Space

Array heap sort uses `O(1)` auxiliary space.

### Final

Heap sort is `O(N log N)` best/average/worst, in-place, and unstable.

### Interview Explanation

"The repeated extracts dominate the linear heap construction."

## Counting, radix, and bucket sort

### Problem

Use key ranges, digits, or distribution assumptions instead of general comparisons.

### Java Code

```java
static int[] countingSort(int[] a, int maxKey) {
    int[] count = new int[maxKey + 1];
    for (int x : a) count[x]++;
    int[] out = new int[a.length];
    int i = 0;
    for (int key = 0; key < count.length; key++) {
        while (count[key]-- > 0) out[i++] = key;
    }
    return out;
}
```

### Math

```text
counting sort = N count + K scan + N write = O(N + K)
radix sort = D passes * O(N + B) = O(D(N+B))
bucket average = distribute N + small bucket sorts + collect N = O(N+B)
bucket worst = dominated by overloaded bucket and inner sort
```

### Space

Counting/radix use count and output arrays; bucket sort stores buckets: usually `O(N+B)`.

### Final

Counting is `O(N+K)`, radix is `O(D(N+B))`, and bucket sort depends on distribution.

### Interview Explanation

"These bounds require assumptions, so they do not break the comparison-sort lower bound."
