**Use case:** Bank support desk — agent creates/reads customer SSN + email + card last-4. Agents call **support-api** only; **customer-service** is internal PII vault; **audit-service** stores every PII access.

**Runnable code:** [Browse full demo →](/spring-secrets-pii-demo)

| Service | Port | What it does |
|---------|------|----------------|
| `support-api` | 8086 | Edge — agents authenticate here; masks PII; calls internal services |
| `customer-service` | 8085 | Vault — AES-GCM encrypted DB columns; `/internal/*` only |
| `audit-service` | 8087 | Compliance — immutable PII access trail |
| `pii-common` | jar | Shared DTOs, masking, audit contract |

        .retrieve()

    email = PiiMasking.maskEmail(email);

## Code — secrets from env (not yaml)

**`EnvironmentSecretProvider`** — same interface for Vault/AWS SM sidecar that writes env:

```java
@Override
public String require(String key) {
    String value = environment.getProperty(key);
    if (value == null || value.isBlank()) {
        throw new IllegalStateException("Required secret/env missing: " + key);
    }
    return value.trim();
}
```

**`SecretsConfig`** — JDBC password from provider:

```java
@Bean
DataSource dataSource(SecretProvider secrets) {
    return DataSourceBuilder.create()
            .url("jdbc:postgresql://...")
            .username("app")
            .password(secrets.require("DB_PASSWORD"))
            .build();
}
```

**`application.yml` — placeholders only:**

```yaml
# Required env: DB_PASSWORD, PII_ENCRYPTION_KEY, API_BASIC_PASSWORD, PII_ADMIN_PASSWORD
spring:
  datasource:
    password: ${DB_PASSWORD}   # injected by K8s — never commit value
```

## Code — secrets from env (not yaml)

**`AesGcmAttributeConverter`** on entity columns:

```java
@Convert(converter = AesGcmAttributeConverter.class)
@Column(nullable = false, length = 512)
private String emailEncrypted;

@Convert(converter = AesGcmAttributeConverter.class)
@Column(nullable = false, length = 512)
private String ssnEncrypted;
```

Key loaded at startup from env — **`EncryptionKeyHolder`**:

```java
@PostConstruct
void init() {
    String base64Key = secrets.require("PII_ENCRYPTION_KEY");
    this.cipher = AesGcmCipher.fromBase64Key(base64Key);
}
```

Prod: key from KMS (envelope) → env inject. Dev: `openssl rand -base64 32`.

## Code — masked API + role gate

**`CustomerService.toResponse`** — never return full SSN to support:

```java
if (masked) {
    email = PiiMasking.maskEmail(email);
    ssn = PiiMasking.maskSsn(ssn);
}
return new CustomerResponse(..., masked, ...);
```

**`CustomerController`** — explicit opt-in for full PII:

```java
@GetMapping("/{id}")
@PreAuthorize("hasAnyRole('SUPPORT','PII_ADMIN')")
public CustomerResponse get(@PathVariable UUID id,
        @RequestParam(defaultValue = "false") boolean fullPii) {
    return customerService.get(id, fullPii);
}
```

Inside service: `fullPii && !hasRole(PII_ADMIN)` → **403**.

## Code — audit + log redaction

**`PiiAccessAuditAspect`** — every PII read → `PII_AUDIT` logger (ship to SIEM):

```java
auditLog.info("event={} actor={} customerId={} fullPii={} ip={}",
        "READ_CUSTOMER", actor, customerId, fullPii, clientIp);
```

**`SecretSanitizer`** + **`PiiMaskingConverter`** in `logback-spring.xml`:

```xml
<conversionRule conversionWord="safeMsg"
    converterClass="com.vibhu.security.pii.logging.PiiMaskingConverter"/>
<pattern>%d %-5level - %safeMsg%n</pattern>
```

Redacts: `password=`, `Bearer …`, SSN `123-45-6789`.

## K8s — inject secrets (copy-paste)

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: customer-service-secrets
type: Opaque
stringData:
  DB_PASSWORD: "<from-vault>"
  PII_ENCRYPTION_KEY: "<base64-32-bytes-from-kms>"
  API_BASIC_PASSWORD: "<rotated>"
  PII_ADMIN_PASSWORD: "<rotated>"
---
apiVersion: apps/v1
kind: Deployment
spec:
  template:
    spec:
      containers:
        - name: customer-service
          envFrom:
            - secretRef:
                name: customer-service-secrets
          # NEVER mount secrets as files in world-readable paths without need
```

**External Secrets Operator pattern:** Vault → `ExternalSecret` → K8s `Secret` → pod env (same Spring code).

## Corner cases — symptom → fix

| Symptom | Cause | Fix |
|---------|-------|-----|
| App won't start: `Required secret/env missing` | K8s Secret not mounted | Check `envFrom` + secret name/namespace |
| `PII key must be 32 bytes` | Wrong base64 length | `openssl rand -base64 32` — decode must be exactly 32 bytes |
| Support sees full SSN in JSON | `toResponse(..., false)` on read | Default `masked=true`; gate `fullPii` by role |
| PII in Splunk/Datadog | `log.info("email=" + email)` | Mask before log; enable `PiiMaskingConverter` |
| DB dump exposes SSN | Plaintext column | `@Convert` encrypt or Postgres pgcrypto/TDE |
| `/actuator/env` shows secrets | Boot actuator exposed | `management.endpoints.web.exposure.include=health` only |
| Secret in git history | Committed `.env` | Rotate secret + `git filter-repo`; block in pre-commit |
| Decrypt fails after deploy | Key rotated without re-encrypt | Dual-key read window + batch re-encrypt job |
| Hibernate `Converter` NPE | Converter not a Spring bean | `@Component` on converter + Boot 3 JPA auto-config |
| 403 on valid admin | Role name mismatch | Spring expects `ROLE_PII_ADMIN` in `@PreAuthorize` |

## 30-second interview answer

> Agents call **support-api** only — it masks PII by default and gates `?fullPii=true` behind `ROLE_PII_ADMIN`. **customer-service** is an internal vault: AES-256-GCM encrypted columns, `/internal/*` endpoints, service credentials only. Every read ships an audit event to **audit-service** with actor, customer id, and IP. Secrets come from K8s/Vault env inject — never yaml or git.
