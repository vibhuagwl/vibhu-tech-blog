# Pattern Selection Guide

Use pressure, not pattern names.

- Complex construction -> Builder
- One of many implementations -> Factory Method
- Families of related services -> Abstract Factory
- Swap algorithm -> Strategy
- Request pipeline -> Chain of Responsibility
- One event, many listeners -> Observer
- Lifecycle-specific behavior -> State
- Runtime behavior wrapping -> Decorator
- One simple entry point -> Facade
- Access control/logging/cache before real object -> Proxy
