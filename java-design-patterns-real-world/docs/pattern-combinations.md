# Pattern Combinations

## Payment system

- Facade as entry point
- Chain for validation
- Strategy for payment method
- Factory for gateway selection
- Adapter for legacy gateway integration
- Decorator for logging/metrics/retry
- State for lifecycle transitions
- Observer for audit/notification/reporting

## Kafka-style event flow

- Observer for event fanout
- Strategy for message processing choice
- Decorator for logging/metrics
- Chain for validation before publish
